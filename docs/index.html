What is Best Game?

Your library meets real-time Twitch data

Which game in my library should I play today?

Every variety streamer asks this before hitting "Go Live." You own hundreds of games, but only a handful have real audiences on Twitch at any given moment. Best Game answers that question with data.

It reads your Steam, GOG, and Epic Games libraries, matches every game to its Twitch category, pulls live viewer counts, and shows you a dashboard of game cards ranked by how likely a small streamer is to pick up organic viewers.

Everything runs locally on your PC. No accounts to create, no data leaves your machine.

Quick Start

Get up and running in under 5 minutes

1

Download the project

Click the green Code button on the GitHub repo and select Download ZIP. Extract it anywhere on your PC.

2

Run the setup script

Double-click setup_windows.bat. It downloads a portable copy of Python, creates a virtual environment, and installs all dependencies — nothing installs system-wide.

3

Launch the dashboard

Double-click run.bat. Your browser opens automatically. Accept the localhost certificate warning (normal for local HTTPS), then enter your API keys in Settings.

Credentials

Free API keys you'll need

The dashboard needs a few free API keys. You set these once from the Settings page (gear icon in the top-right corner of the dashboard).

Steam Web API Key

  1. Go to steamcommunity.com/dev/apikey
  2. Log in with your Steam account
  3. Enter any domain name (e.g. localhost) and agree to the terms
  4. Copy the key and paste it into Settings

Steam User ID

Tells the app whose game library to fetch. Use your custom profile name, SteamID64, or the numeric folder inside Steam/userdata/. The Settings page resolves custom names automatically.

Twitch Client ID & Secret

  1. Go to dev.twitch.tv/console
  2. Click Register Your Application
  3. Give it any name (e.g. "Best Game")
  4. Set OAuth Redirect URL to: https://localhost:5000/auth/twitch/callback
  5. Choose Confidential as the client type
  6. Click New Secret and copy both the Client ID and Secret
  7. Paste them into Settings
  8. Click Connect Twitch to enable one-click stream updates

How it works

  1. Steam Web API returns your owned games
  2. Games are matched to Twitch categories via the Twitch Helix API
  3. Live viewer counts are fetched for each matched category
  4. Store metadata enriches each game card with genres, tags, and descriptions
  5. A discovery score is calculated (visibility, demand, audience depth, competition)
  6. Cards are rendered in the browser and sortable by your chosen criteria
  7. A background collector snapshots viewer counts every 15 minutes for historical charts
